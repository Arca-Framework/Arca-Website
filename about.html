About Arca

A framework that feels like one piece.

Arca is a free FiveM roleplay framework: one core and every system a city needs, designed, written and styled together. It is created and maintained by ScapeScripts.

arca by ScapeScripts
Why it exists

Most servers run on patchwork

A typical FiveM roleplay server is dozens of unrelated scripts glued together. Every one has its own look, its own way of storing data and its own idea of how money, jobs or items work. Menus don't match, updates break each other, and server owners spend more time fixing conflicts than building their city.

Arca was started to fix that. Instead of collecting scripts, it is built as one system:

  • One core. Players, money, jobs, callbacks and UI live in arca_core, and every module uses it the same way.
  • One design. Inventory, phone, bank, HUD, menus and jobs share the same visual language, so the whole server feels like one game.
  • Modern code. Lua 5.4, OneSync, server-side checks on everything that matters, and documentation for every export.
  • No lock-in. Arca answers as qb-core, so most existing qb scripts keep working while you move over.
